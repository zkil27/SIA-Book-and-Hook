# Tech Stack & Critical Gotchas

## Stack (pinned versions in package.json)

- **Next.js 16.3.4** (App Router) + **React 19.2** — see the warning below.
- **TypeScript 5** (strict mode).
- **NextAuth v5 beta** (`next-auth@5.0.0-beta.x`) — Credentials provider +
  `@auth/prisma-adapter`, JWT session strategy.
- **Prisma 5** (`@prisma/client`, `prisma`) over **PostgreSQL on Supabase**.
- **Tailwind CSS v4** (`@tailwindcss/postcss`). Docs mention shadcn/ui as the
  intended component lib; not yet installed.
- **bcryptjs** for password hashing, **zod** for validation.
- Package manager: **npm** (package-lock.json present). OS: **Windows /
  PowerShell** — use `;` not `&&`, and `$env:VAR` not `%VAR%`.

## Next.js 16 warning (read before writing Next.js code)

This is NOT the Next.js in your training data. It has breaking changes to APIs,
conventions, and file structure. Before writing routes, layouts, server actions,
or config, read the relevant guide under `node_modules/next/dist/docs/`. The
`AGENTS.md` block that says this is auto-generated by `next dev` — leave it in
place. Example already-changed API: `RootLayout` uses `LayoutProps<"/">`.

## Prisma / Supabase (the part that eats days)

Two connection strings are required and different — see #[[file:.env.example]]:

- `DATABASE_URL` — pooled (port 6543, `?pgbouncer=true`). App runtime.
- `DIRECT_URL` — direct (port 5432). Migrations only. Migrations CANNOT run
  through the pooler.

Both must be set locally AND in Vercel env vars for all environments.
Instantiate `PrismaClient` only via the singleton in #[[file:lib/prisma.ts]] —
a stray `new PrismaClient()` causes "Too many connections".

## Known build/deploy issue to fix

`package.json` `build` is plain `next build`. For Vercel it MUST be
`prisma generate && next build` (and `postinstall: prisma generate`), or the
cached Prisma client goes stale and the build fails cryptically. See
#[[file:docs/deployment.md]]. Note the existing `postinstall` runs
`prisma skills sync` — unrelated leftover; the composer skill files are NOT used
by this project (standard Prisma, not @prisma/composer).

## Commands

- Dev server: `npm run dev` — long-running; tell the user to run it, do not
  launch it in a blocking terminal call.
- Lint: `npm run lint` (eslint). Typecheck: `npx tsc --noEmit`.
- Prisma: `npx prisma migrate dev --name <slug>`, `npx prisma generate`,
  `npx prisma db seed` (seed script does not exist yet — see structure.md).

## Money & data conventions

- Prices are **integers in centavos** everywhere (₱299.00 → `29900`). Convert to
  pesos only at display time. Never use floats for money.
- Products are **soft-deleted** (`active` flag), never hard-deleted.
